# algorithms-and-ds-handbook

Коллекция алгоритмов и структур данных на Python.

## Содержимое
- **Сортировки**: QuickSort (3-Way), MergeSort, HeapSort, RadixSort, TimSort.
- **Графы**: BFS, DFS, алгоритм Дейкстры (куча), A*, Флойд-Уоршелл, компоненты сильной связности Тарьяна.
- **Деревья и структуры**: Дерево отрезков с ленивым распространением (Segment Tree with Lazy Propagation), дерево Фенвика, система непересекающихся множеств (DSU), префиксное дерево (Trie).
- **Строки**: Кнут-Моррис-Пратт (KMP), Z-функция, полиномиальный хеш Рабина-Карпа.
