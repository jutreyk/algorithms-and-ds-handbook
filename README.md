# algorithms-and-ds-handbook

Набор олимпиадных алгоритмов и структур данных на Python со скриптом замера производительности.

## Реализованные алгоритмы

- **Сортировки:** 3-way QuickSort, MergeSort, HeapSort, RadixSort, TimSort.
- **Графы:** BFS, DFS, Дейкстра с бинарной кучей, A*, Флойд-Уоршелл, поиск компонент сильной связности (Тарьян).
- **Деревья и структуры:** дерево отрезков с ленивым проталкиванием (Lazy Segment Tree), дерево Фенвика, СНМ (DSU), префиксное дерево (Trie).
- **Строки:** КМП (Кнут-Моррис-Пратт), Z-функция, полиномиальный хеш Рабина-Карпа.

## Запуск бенчмарка

Скрипт генерирует тестовые массивы разного размера и замеряет время выполнения:

```bash
pip install rich
python benchmarks.py
```
